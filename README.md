# South Mart
A multi-user e-commerce marketplace that allows customers to browse products and place orders.

The application provides administrators with tools to manage product listings, inventory and customer orders.

The system aims to provide a reliable shopping experience through secure authentication, a user-friendly layout, efficient database operations, transactional order processing and performance optimisation.

# Objectives
- Build a working full-stack e-commerce application.
- Develop RESTful backend APIs using Java and Spring Boot.
- Implement secure authentication.
- Design and implement a relational database using PostgreSQL.
- Implement secure authentication and role-based authorisation.
- Develop reliable checkout and inventory management functionality.
- Optimise UX through search and favourite functionality.

# Features

**MVP**

- Customer registration and login
- Product catalogue
- Product search
- Product categories
- Product details
- Shopping Basket
- Checkout
- Order creation
- Order history
- Admin product management
- Inventory management
